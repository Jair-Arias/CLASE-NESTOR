🎭 Polimorfismo en JavaScript

El polimorfismo permite que diferentes clases respondan al mismo método de manera diferente.

Ejemplo: Sonidos de Animales

// Clase base class Animal { constructor(nombre) { this.nombre = nombre; } // Método que será sobrescrito (polimorfismo) hacerSonido() { return "El animal hace un sonido"; } } // Clases hijas que sobrescriben el método class Perro extends Animal { hacerSonido() { return "🐶 ¡Guau guau!"; } } class Gato extends Animal { hacerSonido() { return "🐱 ¡Miau miau!"; } } class Vaca extends Animal { hacerSonido() { return "🐮 ¡Muuu!"; } } class Pato extends Animal { hacerSonido() { return "🦆 ¡Cuac cuac!"; } }
